# WRO 2025 Rover Vision

OpenMV, Matrix Mini R4, and MQTT tooling from a WRO 2025 robotics project.

The complete sanitized snapshot is in [`wro_2025/`](wro_2025/). It includes the camera scripts, scanner sketch, renamed MQTT control console, and read-only MQTT map viewer. The detailed setup, hardware notes, data flow, and validation steps are in [`wro_2025/README.md`](wro_2025/README.md).

This repository is a historical project snapshot rather than a complete competition-ready robot. Credentials and private broker addresses were replaced with placeholders before publication.
